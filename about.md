# features + use cases

it starts with objects.

### objects

*every**thing***. is an object. *every **property***. is a tag.

everything — note/doc, task, event, time segment, capture, whiteboard, or flashcard — is an object.

[from the github]

- there are defining object types (***object data types***) (techinically still tags) that define what an object is; i.e. task, text/doc/note/jot (rhyme semi-intended), event, time segment, capture, whiteboard, or flashcard…
- …then, there are custom object types (***object info types***) that further define what an object is beyond the data type, such as "person" or "link"...
- …and, there are ***object tags*** that add more information/context to an object and purpose (ie how it should be used), such as "youtube video" or "app".

however, your tesseract is made of (a little) more than just objects and tags.

### tesseract structure

[from the “old” notion doc]

your tesseract has a vault where you keep your second brain. your vault has spaces to seperate but unify the areas of your life.

- all spaces are in a vault, but not all vaults have spaces. a space is only named if there is more than one in a vault; otherwise there is only the vault.
- someone who has a non-creative job could have 2 vaults: one for work and one for personal. but most people would have one vault and their job and school would be in seperate spaces from their personal space but still in the same vault.
- basically spaces are optional and only used if more minute organization is required.

everything (every unit) is an object. objects have tags and types. objects can be sorted into folders or just kept in the vault (folder).

everything (most organization) is a tag. tags are the primary organization method.

folders can have a note linked to them like nottion.

objects can have block types *or* just text *or* no blocks at all if applicable.

the main object types are undeletable and are the core functions of tesseract.

ui-wise, panels can organize your view. the default is just a tab bar, sidebar, and viewport (the tab bar is linked to the viewport and only visible with more than one object open by default. these are only collapsable, not removable. however many more panels can be added to the ui like niko, calendar widgets, the omniview, and more viewports.

the command bar allows you to save and interact with content and features from tesseract from anywhere on your device — and inside tesseract.
