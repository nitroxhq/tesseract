## Overview

**Tesseract** is an all-in-one productivity supertool created by [Nitrox](https://nitroxhq.github.io/). Designed for students, creators, and professionals, Tesseract eliminates the fragmentation of modern productivity by unifying your notes, tasks, calendar, time tracking, flashcards, databases, and whiteboards into a single, cohesive experience.

Instead of forcing your thoughts into isolated silos or rigid folder trees, Tesseract is built on an **object-based** and **file-first** architecture:

- **Object-Based Knowledge:** Connect notes, tasks, projects, and ideas through meaningful relationships rather than rigid folder hierarchies.
- **File-First Freedom:** Your data belongs to you. Stored locally in open formats with no proprietary vendor lock-in.
- **Privacy by Design:** Local-first architecture ensures your thoughts stay private and secure on your machine.
- **Zero-Friction AI:** An unobtrusive assistant designed to accelerate learning, organization, and execution without getting in the way.

## 🚀 Running the Landing Page Locally

This repository contains the official landing page and web showcase for Tesseract. ***For now***, it is built with zero build tools or package managers using clean HTML5, CSS3, and ES6 JavaScript.

Because the site dynamically loads [`navbar.html`](navbar.html) via `fetch()`, run it through a local HTTP server rather than opening `index.html` via `file://`:

### Using Python
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Using Node.js
```bash
npx serve .
# or
npx live-server
```

### Using VS Code
Install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.
